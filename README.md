# GradAspal 🏗️

Aplikasi web berbasis Streamlit untuk analisis dan visualisasi gradasi agregat campuran aspal.

## 🚀 Cara Menjalankan

1. Clone repositori ini:
   ```bash
   git clone https://github.com/USERNAME/gradaspal-web-app.git
   cd gradaspal-web-app
   ```

2. Install dependensi:
   ```bash
   pip install -r requirements.txt
   ```

3. Jalankan aplikasi:
   ```bash
   streamlit run app.py
   ```
